---------- EX01 ----------
Objectif :
	Creer un programme qui renvoie la value d'un bitcoin a une certaine date
	- Le programme doit utiliser la database data.csv qui regroupe la value des bitcoins au court du temps
	- Le programme prendra comme input une deuxieme database, regroupant differente date/prix a evaluer

Regles a respecter :
	- btc					=> Nom du programme
	- Fichier				=> Argument du programme
	- date | value			=> Ligne valide
	- Year-Month-Day		=> Date valide
	- 0 < Float/Int < 1000	=> Valeur valide

!!! 
Si pas de date correspondante prendre
la plus recente de la date correspondante
!!!

Containers utilise :
	std::map
